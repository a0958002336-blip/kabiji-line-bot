# 卡比集機器人 — 部署手冊（rc-2）

> 對象：非工程師也能照著點。全程約 10 分鐘。
> 重點：**先備份 → 更新既有部署（網址不變）→ 快篩 8 項 → 有問題就回退**。
> 版本：`rc-2`（git commit `cbb01a6`，分支 develop）。

---

## 步驟 0：部署前備份（務必先做，2 分鐘）

### 0-1 備份 Google 試算表（資料）
1. 打開機器人的 Google 試算表。
2. 左上角「檔案」→「建立副本」。
3. 命名為 `卡比集資料備份_YYYYMMDD`（例：`卡比集資料備份_20260706`）→ 建立。
   - 這樣萬一資料出錯，有一份當天的完整副本。

### 0-2 記下目前線上版本（程式）
1. 打開 Apps Script 專案（在試算表「擴充功能」→「Apps Script」）。
2. 右上「部署」→「管理部署作業」。
3. 看到目前的「Web 應用程式」部署，點進去，**記下目前的「版本」號碼**（例：版本 7）。
   - 萬一新版有問題，就是回退到「這個版本」。

---

## 步驟 1：更新程式碼

1. 取得最新程式：打開檔案 `卡比集機器人_repo/卡比集機器人.gs`，**全選、複製全部內容**。
   （若用 GitHub：進 repo → `卡比集機器人.gs` → 複製全文。）
2. 回到 Apps Script 編輯器，開啟對應的檔案（通常是 `Code.gs` 或 `卡比集機器人.gs`）。
3. 編輯器內**全選（Ctrl+A）→ 刪除 → 貼上剛才複製的全文**。
4. 按上方「💾 儲存專案」（或 Ctrl+S）。

---

## 步驟 2：更新既有部署（★網址不會變 — 關鍵）

> ⚠️ **不要**按「新增部署作業」——那會產生**新的 Web App 網址**，LINE 就會連不到。
> 一定要**編輯既有的部署**，只換版本。

1. 右上「部署」→「管理部署作業」。
2. 找到現有的「Web 應用程式」那一列，點右上角**鉛筆（編輯）圖示**。
3. 「版本」下拉 → 選「**新版本**」。
4. 「說明」可填 `rc-2 2026/07/06`。
5. 按「**部署**」。
6. 完成後，確認顯示的「Web 應用程式」網址**和之前一樣**（沒變就對了，LINE 不用改設定）。

---

## 步驟 3：確認生效

在 LINE 管理群組（老闆本人）打 `#版本`。
- 看到版本橫幅 = 新程式已生效 ✅

---

## 步驟 3.5：啟用電錶排程觸發器（v3.4.5 起，部署後跑一次即可）

> 只有**第一次**部署 v3.4.5（或觸發器被刪掉）時要做；做過就不用再做。

1. Apps Script 編輯器上方，函式下拉選單選 **`setupMeterTriggers`**。
2. 按「▶ 執行」。首次可能要求授權 → 用機器人的 Google 帳號同意。
3. 執行完，回 LINE 打 **`#電錶提醒`**，看到「早報觸發器 ✅ 已建立／追抄觸發器 ✅ 已建立」就成功。
   - 之後每月 1 號 08:00 會在管理群提醒抄錶，當天起每晚 20:00 追未抄到抄完。
   - （每日備份的 `setupBackupTrigger` 同理，若未啟用過也在這裡跑一次。）

## 步驟 4：快篩 8 項（照另一份清單）

打開 `docs/RC_回歸測試清單_v2.58.md`，**逐項在 LINE 實測打勾**。
重點必測：寄運單、冰庫出庫扣庫存、打卡（含「老闆上班了嗎」不登記）、外勤、收款全流程、誤觸防呆、出勤統計別名合併。

- 8 項全過 → 上線完成 🎉
- 有任一項不符 → 進入下面「回退」。

---

## 步驟 5：出問題就回退（把版本切回舊版）

> 回退只切「程式版本」，**不會動到資料**；資料另有步驟 0-1 的副本保險。

1. 右上「部署」→「管理部署作業」→ 現有 Web 應用程式 → **鉛筆（編輯）**。
2. 「版本」下拉 → 選**步驟 0-2 記下的舊版本號**（例：版本 7）。
3. 按「部署」。
4. 回 LINE 打 `#版本` 確認回到舊版行為。
5. 把「哪一項失敗、你打了什麼、機器人回什麼」記下來回報，工程端再修。

**（進階／有原始碼者）** 也可用 git 取回舊程式再貼：
```
git checkout before-all -- 卡比集機器人.gs   # 取回本輪修改前的版本
# 或還原 backups/Code.gs.backup-original / backups/Code.Task*.gs
```
再重覆步驟 1–3 貼上部署。

## 常見問題
- **LINE 沒反應了？** 多半是步驟 2 誤按「新增部署作業」導致網址改變。回「管理部署作業」用**編輯既有**的方式重做；或把新網址填回 LINE Developers 的 Webhook URL。
- **權限提示要不要給？** 首次部署可能要求授權存取試算表，用機器人所屬的 Google 帳號授權即可。
- **未註冊老闆時很多功能被擋？** 這是刻意的（fail-closed 安全）。先用老闆帳號在群組打 `#註冊老闆` 即可。
