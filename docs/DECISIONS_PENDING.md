## D1 — 收款 / 未收款 資料模型（Bug2，最高工程量）
- **問題**：`#未收款`、`收款/收錢` 指令**本檔不存在**；「客戶 匯款 金額」只 append 到「財務改價」，從不對帳；「統整金額」讀的是另一張「群組訊息」加總 `=金額`，還主動濾掉匯款 → 收款永遠不影響未收。
- **目前做法**：匯款 append log（行617/2827）；無應收基準、無沖銷、無 #未收款。
- **建議方案**：新增「應收帳」分頁（客戶／銷貨額／已收／未收），收款時定位客戶未收列並沖銷、找不到客戶代號要回報失敗；新增 `#未收款` 讀同一張表。
- **影響範圍**：新資料表 + Router 新增「收款/未收款」handler + 完整 log。中大工程。
- **風險**：需先定義「未收＝銷貨額−已收」的**銷貨額來源**（用寄運資料？手動輸入？）。無基準無法算未收。
